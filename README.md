# 🛒 E-commerce Data Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing e-commerce data using SQL to extract meaningful business insights.

The project includes data cleaning using Python, an e-commerce dataset, and a collection of SQL queries designed to solve business-related analytical questions.

The main objective is to understand customer purchasing behavior, sales performance, and product trends through data analysis.

## 📂 Repository Structure

```text
E-commerce-Data-Analysis/
│
├── README.md
├── data_cleaning.py
├── ecommerce_data.csv
├── sql_queries.sql
└── sql_queries_pdf.pdf
```

## 🛠️ Technologies Used

- SQL
- MySQL
- Python
- Pandas
- CSV Dataset

## 🔍 Project Workflow

1. **Data Collection:** Imported the e-commerce dataset from a CSV file.
2. **Data Cleaning:** Used Python to clean and prepare the dataset.
3. **Data Preparation:** Organized the dataset for SQL analysis.
4. **SQL Analysis:** Wrote SQL queries to answer business-related questions.
5. **Insight Generation:** Analyzed query results to identify meaningful patterns and trends.

## 📊 Analysis Objectives

The project explores e-commerce data to understand:

- Sales and revenue performance
- Customer purchasing behavior
- Product performance
- Order and transaction patterns
- Business trends and performance metrics

## 💻 SQL Concepts Applied

The project demonstrates practical SQL concepts, including:

- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd E-commerce-Data-Analysis
```

### 3. Install Required Python Library

```bash
pip install pandas
```

### 4. Run the Data Cleaning Script

```bash
python data_cleaning.py
```

### 5. Perform SQL Analysis

- Import the cleaned dataset into MySQL.
- Open `sql_queries.sql` in MySQL Workbench.
- Execute the SQL queries.
- Review the results to understand the e-commerce data.
